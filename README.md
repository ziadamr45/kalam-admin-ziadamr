# لوحة التحكم السيادية — كلام له لازمة

> **Zero-Trust Elite Security** — محصّنة حتى لو كُشفت كلمة المرور.

لوحة تحكم حصرية لصاحب منصة «كلام له لازمة»: كتابة وإدارة كل المقالات (بنسختيهما القياسية والمشكولة)، إشراف كامل على التعليقات، تحليلات حية، ودرع أمني متعدد الطبقات.

---

## الدرع الأمني (طبقة فوق طبقة)

| الطبقة | التنفيذ |
|--------|---------|
| **تجزئة كلمة المرور** | Argon2id (64MB, t=3, p=4) — معيار OWASP الأول، مقاوم لهجمات GPU |
| **التحقق بخطوتين (2FA/TOTP)** | إلزامي عند أول دخول — متوافق مع Google Authenticator و1Password. **الدخول مستحيل بالاسم والكلمة وحدها** |
| **تشفير سر TOTP** | AES-256-GCM ساكنًا في قاعدة البيانات (مفتاح مشتق scrypt من سر الجلسات) |
| **بصمة الأجهزة** | HMAC-SHA256 لبصمة الجهاز — الدخول من جهاز جديد يطلق تنبيهًا فوريًا، ويمكن رفضه كليًا (`BLOCK_UNTRUSTED_DEVICES=true`) |
| **قواعد IP** | قائمة سماح/حظر تُدار من صفحة الأمان + قائمة بيئة ساكنة + فرض صارم اختياري (`ENFORCE_IP_WHITELIST`) |
| **الجلسات** | JWT (jose, HS256) في كوكيز HttpOnly + Secure + SameSite=Strict — مرتبطة بسجل حي في DB يسمح بالإبطال الفوري |
| **حماية CSRF** | فحص Origin على مستوى الحافة (middleware) + داخل كل مسار API |
| **مكافحة الاختراق (Brute-force)** | عدّاد محاولات في DB: 5 فشل/15 دقيقة = حظر مؤقت + تنبيه CRITICAL، تأخير ثابت ضد استطلاع أسماء المستخدمين |
| **سجل تدقيق** | كل إجراء إداري يُسجل: من، ماذا، من أي IP، متى |
| **تنبيهات أمنية** | دخول جهاز جديد، رمز TOTP خاطئ، IP محظور، حظر مستخدم.. كلها تظهر في لوحة التنبيهات |
| **ترويسات أمان** | X-Frame-Options: DENY، nosniff، Referrer-Policy: no-referrer، HSTS، COOP |

## المزايا الإدارية

- **محرر المقالات الثنائي المتزامن**: حقلان متوازيان — النسخة القياسية + النسخة المشكولة بالكامل، بعدّاد كلمات ووقت قراءة حي، ومزامنة تلقائية اختيارية
- **المختصر المفيد**: حقل يدوي يعرض كنقاط مكثفة
- **إدارة الوسائط**: صورة غلاف + رابط/رفع الملف الصوتي مع اكتشاف المدة تلقائيًا
- **جدول النشر**: نشر فوري / مسودة / جدولة زمنية (Cron كل 5 دقائق ينشر تلقائيًا في موعده)
- **قائمة الفحص الأخلاقي**: 7 معايير «له لازمة» قابلة للتعديل — لا نشر دون اجتيازها (قابل للتبديل)
- **مركز التعليقات**: مراجعة/اعتماد/تعديل/حذف + حظر المستخدم المخالف نهائيًا، مع درجة خطورة وأسباب الفلترة الآلية
- **التحليلات الحية**: زيارات، قراءات متكاملة، معدل إكمال، إعجابات، مشاركات اقتباسات حسب المنصة، الأكثر قراءة، جدول النشر القادم
- **إعادة التوليد الفوري**: لحظة النشر تستدعي `REVALIDATE_SECRET` فتتحدث المنصة العامة **فورًا** (On-Demand ISR)

## التشغيل الأولي (بعد ربط Vercel بقاعدة البيانات)

```bash
# 1. انسخ المتغيرات واملأها
cp .env.example .env.local

# 2. (محليًا) زرع الأقسام والمعايير
npm run seed:sections

# 3. إنشاء حساب المالك (يقرأ ADMIN_USERNAME وADMIN_BOOTSTRAP_PASSWORD)
npm run admin:create

# 4. التشغيل
npm run dev   # يعمل على المنفذ 3001
```

ثم افتح اللوحة → سجّل دخولك → **ستُجبر على تفعيل 2FA** بمسح QR → والجهاز يوثَّق تلقائيًا.

## متغيرات البيئة

| المتغير | الوصف |
|---------|-------|
| `DATABASE_URL` | نفس قاعدة بيانات المنصة العامة **بالضبط** |
| `ADMIN_SESSION_SECRET` | `openssl rand -base64 32` — مفتاح توقيع الجلسات وتشفير TOTP |
| `ADMIN_USERNAME` / `ADMIN_BOOTSTRAP_PASSWORD` | للإنشاء الأولي فقط (احذفهما من Vercel بعدها) |
| `TRUSTED_IPS` | قائمة IP مفصولة بفواصل (اختياري) |
| `ENFORCE_IP_WHITELIST` | `true` = رفض أي IP خارج القائمة قبل صفحة الدخول |
| `BLOCK_UNTRUSTED_DEVICES` | `true` = رفض أي جهاز غير معتمد مسبقًا |
| `CRON_SECRET` | حماية مسار النشر المجدول `/api/cron/publish-scheduled` |
| `PUBLIC_URL` + `REVALIDATE_SECRET` | رابط المنصة العامة وسر إعادة التوليد الفوري |

## النشر على Vercel

1. **Import** المستودع في Vercel.
2. أدخل المتغيرات (نفس `DATABASE_URL` للمنصة العامة).
3. ملف `vercel.json` يفعّل **Cron** تلقائيًا: `/api/cron/publish-scheduled` كل 5 دقائق.
4. شغّل `npm run admin:create` محليًا بنفس `DATABASE_URL` لإنشاء حسابك، ثم احذف `ADMIN_BOOTSTRAP_PASSWORD` من متغيرات Vercel.

```
│   ├── login/               # دخول بطبقتين (كلمة مرور → TOTP)

│   ├── (dashboard)/         # كل الصفحات محمية بـ middleware + guard
│   │   ├── page.tsx         # التحليلات الحية
│   │   ├── articles/        # القائمة + المحرر الثنائي
│   │   ├── comments/        # مركز الإشراف
│   │   ├── users/           # إدارة الحظر
│   │   ├── checklist/       # معايير «له لازمة»
│   │   └── security/        # الأجهزة، IP، التنبيهات، سجل التدقيق
│   └── api/                 # مسارات محمية كلها بـ requireSession + CSRF
├── lib/                     # argon2, TOTP, JWT, AES-GCM, IP rules, session
└── scripts/                 # create-admin, seed-sections
middleware.ts                # الحافة: JWT + CSRF + ترويسات
vercel.json                  # Cron النشر المجدول
```
